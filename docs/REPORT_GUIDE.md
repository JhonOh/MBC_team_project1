# 신고 접수와 처리

기존 DB를 사용하는 환경에서는 `python -m flask --app odysay admin-init-db`를 실행합니다.
SQLite 백업 후 누락된 관리·신고 테이블만 추가합니다. 서버를 재시작하고 브라우저를 새로고침하세요.

커뮤니티 상세의 신고 버튼과 여행지 상세의 리뷰·여행톡·여행톡 댓글 신고 버튼은
신고 사유(1~500자)를 받아 서버에 저장합니다. 로그인이 필요하며 CSRF 검사를 적용합니다.
동일 회원은 같은 대상에 한 번만 신고할 수 있습니다. 재요청은 기존 접수 안내를 반환합니다.
새로고침 후 버튼은 다시 표시될 수 있지만 중복 신고 데이터는 생성되지 않습니다.
신고자와 대상은 서버에서 검증하며 신고 당시 텍스트를 함께 보관합니다.

지정된 관리자 계정으로 `/admin/reports` 또는 관리자 메뉴의 **신고 관리**를 엽니다.
접수·조치 완료·조치 없음 필터로 목록을 확인합니다.
**콘텐츠 관리**에서 필요에 따라 게시 중단 등의 조치를 수행한 뒤,
신고 목록에서 처리 결과와 사유를 기록합니다. 종결만으로 자동 게시 중단되지는 않습니다.
종결한 신고의 처리자·시각·사유는 유지되며 반복 종결로 덮어쓰지 않습니다.
원문 삭제 시 콘텐츠 관리 링크는 404가 되지만 신고 당시 내용은 목록에 남습니다.

관리자에게 이메일·푸시를 발송하는 기능은 없으며 신고 관리 목록에서 확인합니다.

검증: `python -m unittest discover -s tests -p test_reports.py -q`

# 어딧세이 학습자료

현재 프로젝트를 직접 따라 읽고 복습하는 한국어 자료입니다.

1. **[학습 교재](01_학습교재.md)** — 앱 구조, 요청 처리, ORM, 로그인, API, CSS, Git·DB 원리
2. **[실제 코드 지도](02_코드지도.md)** — 현재 앱의 라우트·endpoint·소스 위치, 모델 관계, 핵심 함수 원문
3. **[실습과 복습](03_실습과복습.md)** — 단계별 과제, 개발자 도구 관찰, 12문제와 접어 둔 정답
4. **[메모리 DB 실습 코드](practice_memory_db.py)** — 실제 DB를 바꾸지 않고 조회·관계·rollback·로그인 화면을 확인

처음에는 교재 1~3장을 읽고 실습 1·2를 진행하세요. 이후 로그인·API·CSS로 확장하면 됩니다.

자료 기준은 2026-10-02, 커밋 `fa1c206` 및 현재 내 여행지 페이지의 미커밋 수정입니다.
`source_fingerprints.json`은 당시 소스 파일의 SHA-256 기록입니다. 코드 변경 후 문서가 오래됐는지 판단하는 참고 자료이며, 소스 자체의 백업은 아닙니다.

실습 실행은 프로젝트 최상위에서:

```powershell
.\.venv\Scripts\python.exe study/practice_memory_db.py
```

현재 환경에서 실행하여 6단계 검사 통과를 확인했습니다. 실습 회원은 메모리 DB 전용이며 실제 로그인 계정이 아닙니다.
